### 设计思路举例

**为什么穿透要封顶 5？**
清杂效率若随穿透线性增长，后期会演变成"一枪清屏"，Boss 战变成走过场。给系统一个天花板，比新增一个惩罚机制更干净——同时把"继续堆穿透"的收益导向其他维度（范围、频率）。

**为什么散射第 2 颗弹丸有价值、第 3 颗近乎白给？**
若每颗弹丸都满伤，总 DPS 会随弹丸数线性爆炸。所以第 2 颗给足正反馈（让玩家感受到"弹量 +1"的爽感），第 3 颗起收益递减（防止堆弹量成为唯一解）。**第一档给满足感，第二档开始收。**

**为什么用三系互斥而不是数值平衡？**
火/冰/雷若都能拿，玩家一定会算出唯一最优组合，其他组合沦为废案。互斥后三条路线各自成立——**玩家选择变少了，但每个选择都更有意义**。这是 Roguelike 里"限制即内容"的思路。

## 为什么是游戏策划

经济学和游戏设计有个共通点：**都是在约束条件下做取舍**。

经济学教我的是——任何选择都有机会成本，资源永远是稀缺的，所以真正的问题从来不是"什么最好"，而是"在当前条件下，什么最值得"。

游戏策划也是一样。玩家的耐心有限、屏幕的信息量有限、开发的时间有限。我做的事情就是回答：**在这些限制里，哪一条路径能让玩家爽到，又不至于把系统玩坏。**

这个项目是我用两年时间给出的答案。
